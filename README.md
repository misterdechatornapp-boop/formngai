# PDF ฟอร์มง่าย

เว็บแอปเปิดไฟล์ PDF → วางช่องกรอก (form field) ทับบนหน้า → กรอกเอง / ส่งต่อให้คนอื่นกรอก / กรอกหลายชุดจาก Google Sheets

## เริ่มใช้งาน (ทดสอบในเครื่อง)

```bash
node serve.js
```

แล้วเปิด http://localhost:8795 · ลองกับไฟล์ `samples/ตัวอย่างฟอร์ม.pdf`

> ต้องเปิดผ่านเซิร์ฟเวอร์ (ไม่ใช่ดับเบิลคลิกไฟล์ index.html) เพราะ pdf.js ใช้ module/worker
> ไม่ต้องติดตั้งอะไรเพิ่ม — ไลบรารีทั้งหมดอยู่ใน `vendor/` และฟอนต์อยู่ใน `fonts/` จึงใช้งานออฟไลน์ได้

## แก้ปัญหาจากเครื่องมือเดิม

| ปัญหาเดิม | วิธีที่แอปนี้แก้ |
|---|---|
| วางช่องให้ตรงยาก | **แตะครั้งเดียว**บนเส้นจุดไข่ปลา/ในช่องตาราง/ในกล่อง ☐ หรือในวงเล็บ `[   ]` → ระบบตรวจเส้นจากภาพหน้าเอกสาร แล้ววัดขนาดช่องให้พอดีเอง (ใช้กับไฟล์สแกนได้ด้วย) |
| ใส่ฟอร์มแล้วเลื่อน | ตำแหน่งเก็บเป็นหน่วย pt ของ PDF ไม่ขึ้นกับการซูม/ขนาดจอ · ลากแล้วดูดเข้าเส้น ช่องอื่น และกึ่งกลางกล่อง/วงเล็บ (กด Alt ค้างเพื่อปิด) · ล็อกตำแหน่งได้ |
| ตารางขนาดกำหนดมาแล้ว | เครื่องมือ **ตาราง**: ลากครอบตาราง → ได้ช่องตรงทุกเซลล์ตามเส้นจริง หรือแบ่งเท่ากันตามจำนวนแถว/คอลัมน์ |
| ต้องวางใหม่ทุกครั้ง | บันทึกอัตโนมัติผูกกับไฟล์ (เปิดไฟล์เดิม = ช่องเดิมกลับมา) · ใช้ช่องจากงานอื่นที่ขนาดหน้าเท่ากัน · แม่แบบ `.json` |
| ภาษาไทยเพี้ยน | จัดรูปตัวอักษรด้วย fontkit แล้ววางทีละ glyph พร้อมตำแหน่งสระ/วรรณยุกต์ (pdf-lib ปกติทิ้งค่านี้) · ตัดคำไทยด้วย `Intl.Segmenter` · พรีวิวบนจอใช้การคำนวณเดียวกับ PDF |
| ข้อมูลเยอะ | แท็บ **ข้อมูลจากตาราง**: วางจาก Google Sheets/Excel, ไฟล์ CSV หรือลิงก์ชีต → จับคู่คอลัมน์กับชื่อช่องอัตโนมัติ → สร้าง PDF ทุกแถว (ไฟล์เดียวหรือ ZIP) |
| ใช้บนมือถือ/แท็บเล็ตลำบาก | แถบเครื่องมือด้านล่าง · แผงเลื่อนขึ้น · บีบนิ้วซูม · “กรอกแบบรายการ” ไม่ต้องจิ้มช่องเล็ก ๆ บนหน้า |

## สร้างช่องอัตโนมัติ (เครื่องมือ “อัตโนมัติ” / ปุ่ม A)
1. **ระบายโซน (ไม่บังคับ)** — สีบอกชนิดช่อง: เทา = ให้ระบบเลือก · น้ำเงิน = ข้อความ · เขียว = ติ๊กถูก · ส้ม = วันที่ · ม่วง = ลายเซ็น (มียางลบ และโหมด “เลื่อนหน้า” สำหรับมือถือ)
   คลิกซ้ายลาก = แปรงวงกลม (เห็นขอบแปรงตามเมาส์) · **คลิกขวาค้างแล้วลาก = ระบายเป็นสี่เหลี่ยม** จากจุดกดถึงจุดปล่อย
   ถ้าระบาย ระบบจะหาเฉพาะในโซนนั้น · โซนที่ไม่มีเส้น/กล่องให้จับ จะได้ช่องตามขนาดที่ระบาย
2. **ค้นหา** หน้านี้หรือทั้งไฟล์ — หา `[ ]` / `( )` / ☐ / วงกลม ◯ (ได้ช่องติ๊กแบบจุด), กล่องเรียงติดกันทีละหลัก (เลขบัตร 13 หลัก/วันเกิด → ช่องละ 1 ตัว จัดกึ่งกลาง), เส้นสำหรับเขียน (….. / ____ ที่มีป้ายกำกับ), ช่องตารางที่ว่าง, กล่องใหญ่ที่ว่าง (→ หลายบรรทัด)
3. **ตรวจก่อนสร้าง** — แตะกรอบเพื่อข้าม หรือปิดทั้งชนิด แล้วกด “สร้าง N ช่อง” (Ctrl+Z ย้อนได้ทั้งชุด)

ชื่อช่องตั้งจากข้อความรอบ ๆ: `Model`, `CHECK BATTERY BIOS - OK`, `ประเภทการยืม - ใช้ในหอผู้ป่วย`, `รายการอุปกรณ์ 1` · ป้าย “ลงชื่อ” → ช่องลายเซ็น, “วันที่/Date” → ช่องวันที่ · “วันที่…เดือน…พ.ศ.…” → 3 ช่องที่ใช้ค่าวันที่เดียวกัน
(ไฟล์สแกนที่ไม่มีข้อความจริงจะได้ชื่อเรียงเลขแทน)

## พรีเซท (สไตล์) และกลุ่ม — แท็บ “สไตล์ & กลุ่ม”
- **พรีเซท** = ชุดสไตล์ที่ตั้งชื่อได้: ฟอนต์ · ตัวหนา · ขนาด (อัตโนมัติ/กำหนด) · สี · จัดแนว — ค่าไหนตั้งเป็น “ไม่กำหนด” ให้แต่ละช่องตั้งเอง · เก็บเป็นคลังกลางใช้ได้ทุกเอกสาร
- **กลุ่ม** = ช่องหลายช่องที่ใช้พรีเซทเดียวกัน: เลือกช่อง → “กลุ่มจากช่องที่เลือก” → เลือกพรีเซทของกลุ่ม · แก้พรีเซททีเดียว ช่องทั้งกลุ่มเปลี่ยนตาม
- ลำดับการใช้ค่า: **ค่าที่พรีเซทของกลุ่มกำหนด > ค่าของช่องเอง > ค่าเริ่มต้น** (ในแผงคุณสมบัติจะขึ้นป้าย “ตามพรีเซท”)
- “ใส่ N ช่อง” ในรายการพรีเซท = คัดลอกค่าลงช่องที่เลือกครั้งเดียว (ไม่ผูกกับพรีเซท)
- แม่แบบ `.json` พกพรีเซทและกลุ่มไปด้วย เปิดบนเครื่องอื่นได้สไตล์เหมือนเดิม

**ฟอนต์ในเครื่อง (ใช้ออฟไลน์):** Sarabun · Kanit · Prompt · Chakra Petch · Taviraj (มีเชิง) · Charmonman / Sriracha / Itim (ลายมือ) — ทุกตัวใช้สัญญาอนุญาต SIL Open Font License 1.1 (จาก Google Fonts) ฝังลงใน PDF ได้ และภาษาไทยจัดรูปถูกต้องทุกฟอนต์

## ชนิดช่อง
ข้อความ · หลายบรรทัด · ติ๊กถูก (✓ ✗ ●) · วันที่ · ลายเซ็น/รูปภาพ (วาด, อัปโหลด, จำลายเซ็นไว้ใช้ซ้ำ)
— หน้าออกแบบแยกสีตามประเภท: ข้อความ น้ำเงิน · หลายบรรทัด ฟ้าอมเขียว · ติ๊กถูก เขียว · วันที่ ส้ม · ลายเซ็น ม่วง (สีเดียวกับไอคอนในแถบเครื่องมือ)

**วันที่** เลือกภาษา ไทย / EN ได้ที่หัวข้อ “รูปแบบวันที่”
- ไทย: 16 ตุลาคม 2569 · 16 ต.ค. 2569 · **16 ต.ค. 69** · 16/10/2569 · 16/10/69 · ศุกร์ 16 ต.ค. 2569 · แยกวัน/เดือน/ปี
- EN: 16 Oct 2026 · 16 October 2026 · Oct 16, 2026 · 16 Oct 26 · 10/16/2026 · Friday, 16 October 2026 · …

ช่องที่**ตั้งชื่อเหมือนกันจะใช้ค่าร่วมกัน** (เช่น ชื่อผู้ยื่นที่ซ้ำหลายหน้า) และชื่อช่องคือสิ่งที่ใช้จับคู่กับหัวคอลัมน์ใน Google Sheets

## ส่งออก
- **PDF ที่กรอกแล้ว** — ฝังข้อความ/ลายเซ็นลงในหน้า
- **PDF ฟอร์มกรอกได้** — ช่อง AcroForm จริง (เลือกใส่ค่าที่กรอกไว้ได้)
- **ทุกแถวจากข้อมูล** — PDF รวมไฟล์เดียว หรือ ZIP แยกไฟล์ (ตั้งชื่อไฟล์จากคอลัมน์)

## โครงสร้าง
```
index.html, css/app.css
js/main.js        หน้าจอหลัก: viewer, ออกแบบช่อง, โหมดกรอก, แผงด้านข้าง, ส่งออก
js/detect.js      ตรวจเส้น/จุดไข่ปลา/ตาราง/กล่อง + การวางอัจฉริยะ + snap
js/textlayout.js  จัดวางข้อความ (ใช้ทั้งพรีวิวและ PDF)
js/exporter.js    สร้าง PDF (flatten / AcroForm) ภาษาไทยถูกต้อง
js/merge.js       CSV/TSV, จับคู่คอลัมน์, Google Sheet
js/store.js       ที่เก็บข้อมูล (IndexedDB) — ชั้นแยกสำหรับต่อออนไลน์ภายหลัง
js/sigpad.js      ลายเซ็น · js/thai.js วันที่ไทย · js/ui.js กล่องโต้ตอบ/เมนู
vendor/           pdf.js 4.10, pdf-lib 1.17, fontkit, fflate (ออฟไลน์)
fonts/            Sarabun (OFL)
sw.js             service worker (ออฟไลน์หลังเปิดครั้งแรกเมื่อโฮสต์ออนไลน์)
```

### รูปแบบข้อมูลช่อง (field)
```json
{ "id": "a1b2", "type": "text|multiline|checkbox|date|signature", "page": 1,
  "x": 130, "y": 124, "w": 200, "h": 17,           // pt, มุมซ้ายบนของหน้า (ตามที่แสดงผล)
  "name": "ชื่อ-สกุล", "fontSize": 0,               // 0 = อัตโนมัติ
  "align": "left|center|right", "vAlign": "top|middle|bottom",
  "color": "#000000", "font": "sarabun", "bold": false,
  "dateFormat": "d mmmm bbbb", "checkStyle": "check",
  "required": false, "locked": false, "group": "หัวฟอร์ม" }
```
กลุ่มของเอกสาร: `doc.groups = [{ "name": "หัวฟอร์ม", "preset": "p-hand-blue" }]` · คลังพรีเซท: IndexedDB `kv/presets`
ค่าที่กรอกเก็บแยกเป็น `values: { [ชื่อช่อง]: ค่า }` (วันที่เก็บเป็น `YYYY-MM-DD`, ลายเซ็นเป็น data URL)
